# Library

I implemented a basic library log application by using **object oriented programming** approach in JavaScript.

## Features

- You can add a new book.
- You can delete a book.
- You can change a book's read status.

## What I practiced?

I basically practice,

- DOM manipulation using JavaScript.
- OOP in JavaScript.
- Combinations of CSS-grid and CSS-flex layout models to make a table-like appearance.
